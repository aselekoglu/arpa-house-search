# ARPA House Search design system

## Sources

- ARPA mark: `aselekoglu/arpa-meal-planner/public/arpa-icon.svg`
- visual language: `aselekoglu/aselekoglu.github.io/design.md` and portfolio CSS

## Palette

Light: paper `#f6f7f4`, ink `#182620`, forest `#376449`, muted `#606b63`, line `#bdc6bd`, soft `#e9ede6`.

Dark counterpart: charcoal `#17151c`, text `#f4f1ea`, lilac `#b7a1de`, muted `#b6adbf`.

## Type

- UI: Arial / Helvetica / system sans
- editorial emphasis: Georgia italic
- technical metadata: system monospace

## Geometry

Use hairline borders, restrained rectangular CTAs, generous whitespace and minimal shadow. Avoid generic stacks of floating rounded SaaS cards.

M0 uses the paper theme as default and defines a dark token counterpart without building a theme-settings feature yet.
