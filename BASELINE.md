# ARPA House Search baseline

## Code baseline

- upstream project: `orangecoding/fredy`
- commit: `2a815c92e6da9cceb9633fb5b96086897a245c35`
- commit date: 2025-12-10
- Fredy version: 15.1.1
- license at this commit: MIT
- Node requirement: `>=22.0.0`

This is intentionally the last Fredy commit immediately before the repository's license changed on December 11, 2025.

## What the MIT baseline already provides

- Node/ESM application runtime
- REST API and authentication
- SQLite storage and numbered migrations
- jobs and scheduling/crons
- provider modules
- Puppeteer/Cheerio extraction
- similarity cache
- notification adapters
- React/Vite/Zustand UI
- test suite

## Modern Fredy boundary

Code introduced after the MIT baseline is not copied into ARPA merely because it exists in the later Fredy repository. Useful ideas may inform independent ARPA implementations, but source-level reuse requires a compatible license or explicit permission.
